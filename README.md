# docscan-privacy

The privacy policy for the [DocScan](https://play.google.com/store/apps/details?id=com.eagle.docscan) Android app, published at
<https://ashir30000-eag.github.io/docscan-privacy/>.

It lives in its own public repository because Google Play requires the policy
at a public URL, and GitHub Pages needs a public repository to serve one. The
app source stays private; only the policy, which is meant to be read by
anyone, is here.

`index.md` is a copy of `PRIVACY.md` in the app repository. Edit it there
first, then copy across, so the two cannot disagree.
